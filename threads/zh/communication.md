如何用视频展示你的工作？

作为学术工作者，我们习惯于用静态的文字、图表来分享和沟通工作。

但很多时候，视频是更清晰传达想法的媒介。

下面分享一些我学到的技巧 🧵

*一开始就满足期待*

我以前觉得开场应该先自我介绍、讲问题多重要、（一大堆不相关的）相关工作，才显得「学术」。

## 如何传播你的研究？

原帖：<https://x.com/jbhuang0604/status/1379448897823776769> · 2021-04-06 · 共 20 条串文

分享关于如何传播研究的想法。

「我非常激动地分享，我们的论文被……接收了！」

恭喜！然后呢？没有人会去翻几千篇被接收论文的列表。没人有那个时间。

看下面的线程 🧵 找例子。

*网站*

给项目网站用容易记的域名，方便别人找到/分享链接。没有学校账号？没关系。为 GitHub 页面注册一个新域名。

例如：
• http://oops.cs.columbia.edu/
• http://crowdsampling.io/
• http://robust-cvd.github.io/

相关链接：
- <http://oops.cs.columbia.edu/>
- <http://crowdsampling.io/>
- <http://robust-cvd.github.io/>

*缩写（Acronym）*

让人容易记住和称呼你的工作。正如 David Patterson 所说，元音很重要。

例如，NeRF 听起来比 NRF 酷多了。

*可下载的结果*

不要把结果视频放在 YouTube 上再内嵌到网站。要让人非常容易地下载（并分享）你的结果。帮助别人帮你传播工作。

不要限制图片/视频大小，尽可能分享最高质量。

*额外结果*

很多时候，你需要花很大力气在多个数据集上构造基线结果。把它们公开出来，方便别人跟进。例如，这项工作的许多引用并不是冲着具体技术贡献来的。

![配图](../media/1379448959219949570-1.jpg)

*补充网站*

把跨数据集、方法和消融的所有结果整理到一个网页上。这让「所有人」（包括我自己）都能交互式地查看结果。

示例：
https://alex04072000.github.io/ObstructionRemoval/website/Obstruction_HTML_CameraReady/pages/reflection.html

*GitHub*

不要把杂乱的研究代码直接丢到 GitHub 上。写清楚说明，简化让代码跑起来所需的步骤。

我喜欢的例子：

*Colab*

不是所有人都有知识/资源在你的 GitHub 代码上搭环境。准备一个 Colab notebook demo（或其他平台），让所有人都能玩一玩你的方法。

*arXiv*

把你所有的论文都放到 arXiv 上。论文被付费墙挡住非常让人沮丧。在特定时间发布论文还能进一步提升曝光/阅读量/影响力。

## 如何清晰沟通？

原帖：<https://x.com/jbhuang0604/status/1520615196498214913> · 2022-05-01 · 共 7 条串文

如何清晰沟通？

我们大部分时间都花在邮件、slack 消息和大量会议上。

但作为学生，没有人教过我怎么好好沟通。（我一路肯定惹烦了很多人……😬）

这里有一个组织信息的模板。

*（1）What？*

你的关键点是什么？请不要讲一个绕来绕去、渐渐才引出重点的故事。没人有那个时间！

👉 找出你的主要信息，放到最前面。

[![GIF 动画预览](../media/1520615204777832449-1.jpg)](../media/1520615204777832449-1.mp4)

▶ [GIF 动画（点击播放）](../media/1520615204777832449-1.mp4)

*（2）So What？*

它为什么与你的工作/项目/团队相关或重要？你的听众为什么要在乎？🤷‍♂️🤷‍♀️

👉 告诉我「为什么」。

[![GIF 动画预览](../media/1520615212474273793-1.jpg)](../media/1520615212474273793-1.mp4)

▶ [GIF 动画（点击播放）](../media/1520615212474273793-1.mp4)

*（3）Now What？*

接下来的*可执行*步骤是什么？
例如：再约一次会？请求反馈？为新任务列出计划？

👉 呼吁具体行动！

[![GIF 动画预览](../media/1520615220271538176-1.jpg)](../media/1520615220271538176-1.mp4)

▶ [GIF 动画（点击播放）](../media/1520615220271538176-1.mp4)

示例：研究

1⃣ What？
这是玩具问题 A 的结果。

2⃣ So what？
这很重要，因为这个实验帮我们只研究问题 A，不被问题 B/C 分心。

3⃣ Now what？
我将继续研究问题 B 和 C。

示例：机会

1⃣ What？
我有兴趣与你合作。

2⃣ So what？
我有相关技能、经验，以及把你最近工作 X 扩展到 Y 和 Z 的具体想法。

3⃣ Now what？
你什么时候方便，我来展示这些具体方向？

祝沟通顺利！

在写和说「任何事」时心里装着 What/So What/Now What 模板，对保持信息清晰简洁非常有用！

希望对你也有帮助！👍

如何设置好的日历邀请？

我们的日历上排满了各种日程（项目会、圆桌、委员会、一对一）🗓️

但大多数日历邀请都极其模糊，导致会议低效。

写好日历邀请的五个建议 👇

*1⃣ 具体的标题*

没人知道「项目更新」或「实习周会」是什么。🙄

给日程起一个具体的标题，对大家都有帮助！

写下会议的具体目标！

你在占用别人的时间。在日历邀请里，告诉他们你想从会议中得到什么。

会议结束前务必回顾一下目标。

*3⃣ 议程*

有多个话题要讨论？

写下来，并为每个话题分配所需的具体时间。

没有议程就不要开会。

## 如何约会议？

原帖：<https://x.com/jbhuang0604/status/1866260228150337632> · 2024-12-09 · 共 6 条串文

如何约会议？

当你请求和别人开会时，你是在占用他们的时间——你想让别人把他们最宝贵、有限的资源花在你自己身上（为了建议、社交、提问和机会）。

以下是我觉得有用的一些建议。

*先主动给出你的空闲时间*

你能做的最烦人的事就是问：

「你能给我列一下你有空的时间段吗？」

这基本等于要求别人把「所有」空闲时间都为你留着。

[![GIF 动画预览](../media/1866260235423265077-1.jpg)](../media/1866260235423265077-1.mp4)

▶ [GIF 动画（点击播放）](../media/1866260235423265077-1.mp4)

*替对方转换时区*

提供空闲时间时，顺手把时间段换算成对方所在时区，方便他们安排日程。

[![GIF 动画预览](../media/1866260243178725419-1.jpg)](../media/1866260243178725419-1.mp4)

▶ [GIF 动画（点击播放）](../media/1866260243178725419-1.mp4)

*列出会议的具体目标*

告诉他们这个会议如何能帮到你。写下你要问的问题。说明你已经做了哪些功课。提供你想讨论内容的背景材料。

让他们确信你不会浪费他们的时间。

[![GIF 动画预览](../media/1866260250497524212-1.jpg)](../media/1866260250497524212-1.mp4)

▶ [GIF 动画（点击播放）](../media/1866260250497524212-1.mp4)

*尽快发出日历邀请*

没有出现在日历上的日程，等于不存在。

时间敲定后，请尽快发出带有详细标题/内容/链接的日历邀请。会前再发一条提醒，告诉他们可以期待什么。

[![GIF 动画预览](../media/1866260257657483323-1.jpg)](../media/1866260257657483323-1.mp4)

▶ [GIF 动画（点击播放）](../media/1866260257657483323-1.mp4)

大多数人都乐于花时间帮助别人。

遵循这些建议能提高别人愿意见你的概率，帮你达成目标！
